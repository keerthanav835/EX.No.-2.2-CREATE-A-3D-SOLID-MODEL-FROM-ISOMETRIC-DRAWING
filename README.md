 EX.No.-2.2 CREATE A 3D SOLID MODEL FROM ISOMETRIC DRAWING


 AIM: 

To create a 3Dmodel from the given isometric drawing using fusion 360 tool. 

REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 
PROCEDURE:
1. Open Fusion 360, select New Design, and create a sketch on the XY plane. Draw the base plate using the Center Rectangle tool with an overall length of 92 mm and the required rounded ends.

2. Use the Fillet tool to round both ends of the base plate with a radius of R18 mm. Maintain the given hole-centre distance of 56 mm.

3. Draw two circles on the base plate using the Circle tool. Set their diameters to Ø16 mm and position them according to the given dimensions. Finish the sketch.

4. Select Extrude and give the base plate the required thickness of 8 mm. Use the Hole or Extrude Cut command to create the two mounting holes.

5. Create a new sketch on the base plate and draw the vertical supporting portion using the Line tool. Maintain the given height of 50 mm and the required width of the support.

6. Use the Extrude command to create the vertical support. Ensure that it is properly connected to the base plate.

7. Create another sketch on the upper portion of the support. Draw the circular boss using two concentric circles with the given diameters Ø30 mm and Ø20 mm.

8. Use the Extrude command to create the upper cylindrical portion. Apply the required extrusion height and use Extrude Cut to create the central hole.

9. Create the upper connecting arm using the Line tool and follow the side-view profile. Maintain the overall horizontal dimension of 83 mm and draw the inclined edge using the given profile.

10. Use the Trim tool to remove unwanted sketch lines and overlapping portions. Apply the necessary finishing operations, check all dimensions, and select Isometric View to inspect the completed 3D model.
